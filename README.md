# ArogyaSahayaLocal

ArogyaSahayaLocal is a smart healthcare assistance Android application built using Kotlin, Jetpack Compose, Room Database, and MVVM Architecture.

The application helps users manage medicines, track health records, receive medicine reminders, access emergency SOS support, connect with ASHA health camps, and maintain medical profiles in a simple and user-friendly way.

---

## Features

### Medicine Reminder System
- Add medicines with dosage details
- Morning / Afternoon / Night scheduling
- Alarm-based medicine reminders
- Full-screen alarm alerts
- Medicine history tracking
- Edit and delete medicine records

### Vital Health Tracking
- Record blood pressure, sugar level, pulse, and temperature
- View complete vital history
- Visual health graph monitoring

### Medical Profile Management
- Store personal medical information
- Blood group details
- Chronic disease information
- Emergency contact details
- Address and patient profile management

### Emergency SOS
- One-tap emergency support access
- Emergency call feature
- Emergency SMS support
- Fast access during urgent situations

### ASHA Connect
- Add and manage local health camps
- Register for health camps
- Track upcoming medical camps
- Village healthcare support system

### User Authentication
- Secure login and registration
- Password update system
- Weekly auto-login session support
